# BOM

## 基线

以根 [README](../../README.md) §2 的《唯一硬件配置基线表》为准。

## 双 BOM / 兼容位

| 选项 | 装配 | 说明 |
| :--- | :--- | :--- |
| RF Option A | 直通（`C46/C47` 贴；`U5/Q1/C24/C27/C31` 全 NC） | **V0.2 量产默认**；无 LNA/SAW |
| RF Option B | LNA ATR2652 + SAW B39162B2651P810 贴装 | 增强灵敏度/抗干扰；**必须 NC 掉 C46/C47** |
| GNSS 模组（**默认**） | **u-blox MAX-M10S-00B**：`R13`=0Ω 贴、`R28`=100Ω 贴、`R27`=NC；Pin15 对地跳线贴 | 唯一默认装配料；固件默认 UBX |
| GNSS 模组（**备份方案，默认不采购/不装配**） | Quectel LC79H：`R13`/`R28`=NC、Pin15 跳线 NC、需要 WAKEUP 时贴 `R27` | 18-LCC 同构；**现有硬件 Pin15 硬接 GND，需先改板加跳线**才可装配 |

## 必填字段（V0.2 起强制）

- 每行必须有 **MPN**；`{Value}` 占位符禁止出现在送厂 BOM。
- DNP/NC 必须显式成列（`DNP` 列 = Y/N），不得只在原理图注释里写。
- 晶振必须标注 `CL`（X1=9pF / X2=8pF）与频差；磁珠必须标注阻抗@100MHz 与额定电流。

## 规则

- 每个 BOM 行包含：位号、料号、封装、数量、DNP/NC、替代料、装配选项。
- 互斥器件必须在 BOM 与原理图同时标注，禁止同时贴装。
- 关键物料（GNSS、IMU、Flash、DCDC、LDO、充电 IC）记录原厂/代理渠道与批次追溯。
- 导出给贴片厂的 BOM/CPL 必须与 Gerber 同版本，附校验和。
